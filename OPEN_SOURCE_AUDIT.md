# Open-source audit

Audit date: 2026-07-20  
Release: 0.2.0

## Policy

A skill is included in the public packages only when its directory contains a license, copying, or notice file. First-party integration wrappers include a local copy of the repository MIT license. This is a conservative redistribution rule; it does not prove that every upstream attribution is perfect, but it avoids knowingly publishing components with no preserved licensing terms.
