# Политика безопасности

Не публикуйте сведения об уязвимостях в открытых issues. Используйте приватное сообщение об уязвимости GitHub, когда функция доступна. Укажите затронутую версию, шаги воспроизведения, последствия и возможное исправление. Не прикладывайте секреты, персональные данные или материалы закрытых репозиториев.

Поддерживаемая версия — последний опубликованный релиз. Исправления для старых веток выпускаются только при отдельном объявлении сопровождающего.
