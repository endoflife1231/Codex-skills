# Участие в разработке

1. Создайте отдельную ветку.
2. Не добавляйте сторонний компонент без подтверждённой лицензии и уведомления об авторстве.
3. Обновляйте английскую и русскую пользовательскую документацию одновременно.
4. Перед pull request выполните проверки дистрибутива, окружения и сборки релиза.
5. Опишите изменение, риски, проверку и происхождение сторонних материалов.
