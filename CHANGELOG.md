# Changelog

All notable changes to this project are documented here.

## [0.2.0] - 2026-07-20

- Added English `README.md` and Russian `README.ru.md`.
- Fixed all repository documentation links to use relative paths.
- Added prerequisites, quick-start commands and top-level command wrappers.
- Added MIT/open-source community files, security policy and repository templates.
- Added GitHub validation and tagged-release workflows.
- Added a conservative license audit and removed 70 skills without bundled licensing terms.
- Rebuilt the public catalog with 184 license-audited skills.
- Replaced the broken release builder and added separate user and repository archives, manifests and SHA-256 checksums.

## [0.1.0] - 2026-07-03

- Initial local Codex Powerpack distribution.
